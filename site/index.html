建造现场

Pylox 是一门从零开始做的脚本语言。负责“读懂程序”的部分用 Python 写，负责“跑得快”的虚拟机用 C 写。现在还一行实现代码都没有，这个网站会跟着它一起长大。

路线 A · 参考实现

        

          树遍历解释器→
          结果
        

        
直接沿着语法树执行。慢，但最容易写对，用来定义“正确答案”。

      

      

        
路线 B · 字节码

        

          字节码编译器→
          字节码文件→
          虚拟机 + 垃圾回收→
          结果
        

        
先翻译成紧凑的指令，再交给 C 写的虚拟机执行，内存也由它自己回收。

      

    

    

      =
      
两条路线的结果必须一模一样。同一批测试程序会在两边各跑一次，输出或退出码有任何不同，就说明有 bug。

    

    

      预置库
      
map、filter、reduce 这类库函数用 Pylox 自己写，顺便检验这门语言够不够用。
